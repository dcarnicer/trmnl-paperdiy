# TRMNL for PaperDIY (community port)

TRMNL firmware for the M5Stack PaperDIY (K159), ESP32-S3 with a 4.7" 960×540
e-paper panel. Unofficial community port, not affiliated with TRMNL or M5Stack.

- Burn `firmware/TRMNLPaperDIY_0x0.bin` at 0x0, or install it from M5Launcher.
- On first boot, join the **TRMNL** Wi-Fi access point, pick your network and,
  for a self-hosted server, enter its URL.
- On battery the device powers itself off between refreshes; press the power
  button to refresh by hand.
